03

      
Two lines, done.

      
No build step, no framework. The element fills its nearest positioned parent and stays behind your content.

    

    
    
      
  1. 
        
    Load the script
    
        
    <script src="https://rezaaryam.github.io/latar/latar.js"></script>
    
      
    2. 
      
  2. 
        
    Put it behind anything
    
        
    <section style="position: relative">
  <latar-bg preset="fog" colors="#0c0a09 #6b3f2a #e8964e #fbe9c8"></latar-bg>
  <h1 style="position: relative">Hello</h1>
</section>
    
      
    3. 
      
  3. 
        
    Or drive it from JavaScript
    
        
    const bg = Latar.mount(document.querySelector(".hero"), { preset: "aurora", interactive: true });
bg.set({ colors: ["#04070f", "#3cf0b0", "#4aa8ff", "#c8ff7a"], speed: 0.6 });
const png = await bg.snapshot(2560, 1440);  // a Blob, ready to download
    
      
    4. 
    


    

      

        Attributes
        
AttributeDefaultWhat it does

        
          
presetmeshmesh, aurora, contour, fog, or dots.

          
colorsper presetFour colors, separated by spaces or commas. The first is the base.

          
speed10 freezes time; 4 is fast.

          
scale1Zoom of the pattern, 0.25 to 4.

          
intensity1How strong the effect is against the base color.

          
grain0.045Film grain on top. Hides banding on cheap screens.

          
interactiveoffThe pattern bends toward the pointer.

          
resolutionper presetRender scale. Soft looks render at half size and nobody can tell.

          
pausedoffDraw one frame and stop.

        
      

    

  


  
  

    

      
04

      
Polite by default.

      
A background should never be the reason a page feels slow.

    

    

      
    
        
  • Stops when you scroll away.An IntersectionObserver pauses drawing the moment the element leaves the screen, and when the tab is hidden.
    • 
        
  • Holds still for people who ask.With reduced motion turned on, it draws a single frame and waits.
    • 
        
  • Knows its budget.Device pixel ratio is capped, soft looks render at half resolution, and no canvas grows past 2.4 million pixels.
    • 
        
  • Falls back gracefully.No WebGL, or a lost context, and the element shows a matching CSS gradient instead of a blank box.
    •
